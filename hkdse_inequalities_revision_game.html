Inequality Rules

  • Solve like an equation: \(ax + b < cx + d\)
  • × / ÷ by a negative ⇒ flip sign: \(-x > a \Rightarrow x < -a\)
  • Clear a fraction ⇒ × LCM: \(\dfrac{ax+b}{c} \Rightarrow ax+b\)
  • "and" ⇒ overlap (intersection): \(a < x\) and \(x < b \Rightarrow a < x < b\)
  • "or" ⇒ union: \(x < a\) or \(x > b\)
  • Chained inequality ⇒ split: \(a < b < c \Rightarrow a < b\) and \(b < c\)
  • Quadratic ≥ 0 for all x ⇒ a > 0 and Δ ≤ 0: \(\Delta = b^2 - 4ac \le 0\)
